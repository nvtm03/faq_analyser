# FAQ Analyser · E5

Ноутбук `faq_e5_duplicates.ipynb` подбирает порог для поиска неполных дублей FAQ по готовым эмбеддингам E5. Веса модели для запуска не нужны.

## Запуск на рабочем компьютере

1. Скачайте ноутбук и положите его рядом с полным `faq_embeddings_final.npy` и `faq_answers_snapshot.pkl` из того же запуска. В первой ячейке укажите пути к двум выгрузкам Excel, векторному кэшу и снимку.
2. Для подбора порога положите рядом локальный `faq_e5_audit.json` с отпечатками и разметкой пар или укажите свой CSV в `BENCHMARK_FILE`.
3. Нажмите **Run All**. Последняя ячейка покажет порог, правило отбора и сравнение на отдельной проверочной выборке. Для записи HTML и Excel выставьте `WRITE_REPORT = True`. При смене порога достаточно повторить последнюю ячейку.

Для ноутбука нужны Python 3.10+, NumPy, pandas и openpyxl. Рабочие выгрузки, готовые векторы, снимок, разметка и отчёты хранятся локально.

## Подбор порога

Карточки из выгрузки сопоставляются с векторами по ID и тексту ответа. Соседи отбираются по cosine E5 отдельно внутри и между продуктами. Сетка сравнивает пороги и правила с проверками условий и направленной вложенностью. Порог выбирается по F1 на части «подбор». Для оценки используется отдельная часть «проверка». В выводе также показан вариант с порогом 0,95 и проверками внутри продукта.

## Тесты

Установите зависимости из `requirements.txt` и выполните `python -m unittest discover -v`. Тесты используют синтетические карточки и векторы.
