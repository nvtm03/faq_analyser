# FAQ Analyser · E5

Первая версия поиска неполных дублей по сохранённым эмбеддингам ответов. Ноутбук — `faq_e5_duplicates.ipynb`. Нужны Python 3.10+, NumPy, pandas и openpyxl. Модель и её веса для запуска не нужны.

## Входные файлы

В первой ячейке укажите пути к двум выгрузкам FAQ, полному `faq_embeddings_final.npy` и `faq_answers_snapshot.pkl` из того же запуска. Вместо локального доверенного PKL можно указать CSV со столбцами «Идентификатор» и «Ответ» в порядке строк массива. Разметку `faq_partial_benchmark.csv` можно подключить при наличии.

В поиск попадают карточки, у которых совпали ID и текст ответа. Число карточек без вектора видно в выводе. `REQUIRE_FULL_COVERAGE = True` требует покрыть всю выгрузку.

## Первый прогон и подбор порога

1. Выполните Run All. В выводе ячейки «prepare» появятся покрытие и число пар выше каждого порога внутри и между продуктами. Это размер пула до проверок контекста.
2. Если есть подходящая разметка, порог подбирается по F1 на размеченной части «подбор». Иначе ноутбук покажет пары из разных диапазонов cosine для ручной проверки.
3. Чтобы попробовать другой порог или убрать межпродуктовые пары, измените `E5_MIN_COSINE` или `SAME_PRODUCT_ONLY` и повторите последнюю ячейку. Уже посчитанные соседи переиспользуются.

Результаты сохраняются в `results/e5_run` как HTML и Excel. Кандидаты отбираются по cosine E5, затем проверяются продукт, операция и условия ответа. Число кандидатов само по себе не измеряет качество. Полный прогон на рабочих векторах предстоит выполнить на рабочем компьютере.

## Проверки кода

Тесты используют синтетические карточки и векторы. Для запуска всех тестов репозитория установите зависимости из `requirements.txt` и выполните `python -m unittest discover -v`.
